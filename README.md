## Shizuku
- [Shizuku官网](https://shizuku.rikka.app/) - [Github](https://github.com/RikkaApps/Shizuku/releases) - 资源占用最小，匹配最快速，无额外功能。在Android17应用列表获取失效导致不能在面板取消相关权限，但不影响基本功能
- thedjchi版 - [Github](https://github.com/thedjchi/Shizuku/releases) - 可全面替换官版，额外支持部分启动时的附属功能，强化后台保活与重启
- [lingyu版](https://lingyu-1qj.pages.dev/Shizuku)  - 可全面替换官版，修复17+应用列表获取，额外支持联网管理/常见工具快捷激活/墓碑模式开关 等，强化后台保活

## Root
- [KernelSU官网](https://kernelsu.org/zh_CN/) - [Github](https://github.com/tiann/KernelSU) - 权限/模块管理器，支持临时root和永久root

- [Magisk面具](https://magiskcn.com/) - [Github](https://github.com/topjohnwu/Magisk)
权限/模块管理器，适合低于Android17设备的永久root管理

- Ghostlock - [Github](https://github.com/YuKongA/ghostlock-app) - 利用攻击漏洞的方式获取临时root，需Shizuku，免解bl锁，免PC，重启失效

## 其它工具推荐
- 爱玩机工具箱 - [版本1](https://aiwanjitool.cn/) - [版本2](https://doc.byyoung.top/)

- [MT管理器](https://mt2.cn/) - 开发者的文件管理器，支持apk文件编辑/签名等众多专业功能。内部收费

- [NP管理器](http://normalplayer.top/) 免费版开发者的文件管理器，近似MT管理器

- [Canta](https://samolego.github.io/Canta/) - [Github](https://github.com/samolego/Canta) - 卸载当前用户系统应用，可还原，需shizuku。
    - 卸载小米[智能服务]会延长系统应用启动时间，直接删除这个目录内所有文件`/storage/emulated/0/Android/data/com.miui.systemAdSolution/files` ，然后新建空白文件 `miad` 就可以无广告了

- [NPatch](https://github.com/7723mod/NPatch) 免root用户的模块管理

- [LSPosed](https://github.com/LSPosed/LSPosed) root用户的模块管理
